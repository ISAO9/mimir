# MIMIR

**Mesh-free Inversion via Multi-network Implicit Representation** — a
differentiable neural-field framework for seismic travel-time tomography
with total generalized variation (TGV²) regularization.

Named after the Norse god whose well at the roots of Yggdrasil preserved
the knowledge of the depths.

This repository accompanies the manuscript

> *Total Generalized Variation regularization closes the gap between
> neural-field and classical methods in seismic travel-time tomography.*

The code reproduces every numerical result, statistical test, and figure
in the manuscript in under one hour on a modern laptop.

---

## What MIMIR does

MIMIR represents a 2D subsurface velocity field as a coordinate-based
multilayer perceptron with Fourier feature embedding, replacing the
classical grid-based slowness vector with a continuous, infinitely
differentiable function. It minimises a Huber data-fit term over
travel-time residuals plus a TGV² regularizer whose auxiliary vector
field is parametrized by a *second* neural network jointly optimized
with the velocity field. This eliminates the inner Chambolle–Pock
primal–dual loop that classically dominates TGV computation.

The repository compares MIMIR against four alternatives on three
controlled synthetic benchmarks (Gaussian anomaly, layered model,
curved-fault model inspired by OpenFWI):

| Method                       | Regularizer                       | Script |
|------------------------------|-----------------------------------|--------|
| Classical FMM–LSMR           | Tikhonov damping + 2D Laplacian   | `10`   |
| MIMIR-TV                     | Total variation, fixed weight     | `22`   |
| MIMIR-TV (curriculum)        | Log-linear annealed TV weight     | `30`   |
| MIMIR-Huber-TV               | Smoothed-L¹ Huber penalty         | `43`   |
| **MIMIR-TGV²**               | Total generalized variation (2nd) | `40`   |

## Quick start

```bash
git clone https://github.com/ISAO9/mimir.git
cd mimir
uv venv && source .venv/bin/activate
uv pip install -e .

# Environment sanity check
python scripts/00_environment_check.py

# Generate synthetic benchmarks (~30 s)
python scripts/01_generate_synthetic_benchmarks.py

# Reproduce the headline result (~20 min on a modern laptop)
python scripts/10_baseline_eikonal_fmm.py       # classical baseline
python scripts/40_train_tgv.py                  # MIMIR-TGV²
python scripts/11_compare_mimir_vs_baseline.py  # composite figure
python scripts/44_verify_final_results.py       # paired t-tests
```

The composite figure and all statistical tests appear in `PDF/` and
`logs/final_verification/`.

To reproduce **every** experiment in the manuscript (about one hour):

```bash
python scripts/01_generate_synthetic_benchmarks.py
python scripts/10_baseline_eikonal_fmm.py
python scripts/21_ablation_fourier_smoothness.py
python scripts/22_train_paper_grade.py
python scripts/30_curriculum_annealing.py
python scripts/40_train_tgv.py
python scripts/42_ablation_tgv_alphas.py
python scripts/43_train_huber_tv.py
python scripts/41_combine_ablation_heatmaps.py
python scripts/11_compare_mimir_vs_baseline.py
python scripts/44_verify_final_results.py
```

## Reproducibility

* Five random seeds per benchmark; seeds are deterministic
  (`20260507 + 17·i`).
* Cross-well acquisition: 12 sources × 24 receivers, 288 rays.
* 5 % multiplicative travel-time noise.
* 8 000 iterations per neural-field run; classical baseline LSMR runs
  until convergence with auto-tuned damping/smoothing.
* All metrics — RMSE, SSIM, Pearson correlation — are computed by
  `mimir.metrics.field` and compared by paired Student's *t*-test in
  `scripts/44_verify_final_results.py`. As a sensitivity check, every
  comparison was also re-run with the non-parametric Wilcoxon
  signed-rank test; qualitative conclusions are preserved.
